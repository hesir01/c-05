## S501A6 选择题（共 5 题，每题 20 分）

### 第 1 题【202603】关于递归函数调用，下列说法错误的是（ ）？
- A. 递归调用层次过深时，可能会耗尽栈空间导致栈溢出
- B. 尾递归函数可以通过编译器优化来避免栈溢出
- C. 所有递归函数都可以通过循环结构来改写，从而避免栈溢出
- D. 栈溢出发生时，程序会抛出异常并可以继续执行后续代码

**答案：D**

**解析：**
- A ✅：每次递归调用都会在系统栈上压入一帧（返回地址、参数、局部变量），层数过深必然耗尽栈空间，导致栈溢出。
- B ✅：尾递归（递归调用是函数的最后一条语句）可以通过编译器的尾调用优化，复用当前栈帧，从而避免栈无限增长。
- C ✅：任何递归都可以改写成等价的循环（迭代）结构——简单递归直接改循环，复杂递归用显式栈模拟；改写后不再占用系统调用栈，可避免栈溢出。
- D ❌：**栈溢出发生时程序通常直接崩溃/终止（如段错误），并不会"抛出异常并继续执行"**。这是本题的错误说法。

### 第 2 题【202503】在程序运行过程中，如果递归调用的层数过多，会因为（ ）引发错误。
- A. 系统分配的栈空间溢出
- B. 系统分配的堆空间溢出
- C. 系统分配的队列空间溢出
- D. 系统分配的链表空间溢出

**答案：A**

**解析：**
递归调用使用**栈**保存每次调用的现场（返回地址、局部变量等）。调用层数过多时，系统栈空间被耗尽，产生**栈溢出**。
- 堆（heap）用于动态分配内存（new/malloc），与递归调用深度无关；
- 队列、链表不是系统给程序分配的固定区域。故选 A。

### 第 3 题【202403】递归函数在调用自身时，必须满足（ ），以避免无限递归？
- A. 有终止条件
- B. 函数参数递减（或递增）
- C. 函数返回值固定
- D. 以上都对

**答案：A**

**解析：**
避免无限递归的**必要条件是有终止条件（递归出口/base case）**——递归到某一层时能直接返回，不再调用自己。
- B ❌：参数"递减/递增"只是保证向终止条件逼近的常见手段，但并非必须（例如参数向中间靠拢、按步长变化等，都不一定单调递减）；它不是必要条件。
- C ❌：返回值固定与是否无限递归无关。
故选 A（"有终止条件"才是必须满足的）。

### 第 4 题【202309】有关下面 C++ 代码说法错误的是（ ）？
```cpp
// sumA()和sumB()用于求从1到N之和
#include <bits/stdc++.h>
using namespace std;
int sumA(int n) {
    int sum = 0;
    for (int i = 1; i < n + 1; i++)
        sum += i;
    return sum;
}
int sumB(int n) {
    if (n == 1)
        return 1;
    else
        return n + sumB(n - 1);
}
int main() {
    int n = 0;
    cin >> n;
    cout << sumA(n) << " " << sumB(n) << endl;
    return 0;
}
```
- A. sumA() 用循环方式求从 1 到 N 之和，sumB() 用递归方式求从 1 到 N 之和。
- B. 默认情况下，如果输入正整数 1000，能实现求从 1 到 1000 之和。
- C. 默认情况下，如果输入正整数 100000，能实现求从 1 到 100000 之和。
- D. 一般说来，sumA() 的效率高于 sumB()。

**答案：C**

**解析：**
- A ✅：sumA 用 for 循环，sumB 用递归（`n + sumB(n-1)`），描述正确。
- B ✅：递归深度 1000 层，远小于默认栈容量（通常 8MB），能正常算完。
- C ❌：递归深度 100000 层会**耗尽栈空间导致栈溢出**，程序崩溃，无法算出结果——这是错误说法。
- D ✅：递归版本每次调用都有函数调用开销（压栈/出栈），一般比循环慢，效率更低。
故选 C。

### 第 5 题【202512】下面给出了阶乘计算的两种方式，以下说法正确的是（ ）？
```cpp
int factorial1(int n) {
    if (n <= 1) return 1;
    return n * factorial1(n - 1);
}
int factorial2(int n) {
    int acc = 1;
    while (n > 1) {
        acc = n * acc;
        n = n - 1;
    }
    return acc;
}
```
- A. 上面两种实现方式的时间复杂度相同，都为 O(n)
- B. 上面两种实现方式的空间复杂度相同，都为 O(n)
- C. 上面两种实现方式的空间复杂度相同，都为 O(1)
- D. 函数 factorial1() 的时间复杂度为 O(2^n)，函数 factorial2() 的时间复杂度为 O(n)

**答案：A**

**解析：**
- **时间**：factorial1 递归 n 次、factorial2 循环 n 次，都执行 n 次乘法，**时间复杂度都是 O(n)** → A 对、D 错。
- **空间**：
  - factorial1 递归深度 n，需要 n 层系统栈，**空间 O(n)**；
  - factorial2 只用几个局部变量，**空间 O(1)**；
  - 两者空间复杂度**不相同** → B、C 都错。
故选 A。

## S501A7 判断题（共 5 题，每题 20 分，A=正确 B=错误）

### 第 1 题【202412】递归算法必须有一个明确的结束条件，否则会导致无限递归并可能引发栈溢出。
**答案：A（正确）**

**解析：** 递归的核心三要素：递归出口（终止条件）、递归调用、向出口逼近。没有终止条件的递归会无限调用自身，系统栈被撑爆，最终栈溢出。说法正确。

---

### 第 2 题【202509】所有递归算法都可以转换为迭代算法。
**答案：A（正确）**

**解析：** 理论上递归与迭代是等价的，任何递归算法都可以转换为迭代（循环）算法——简单递归直接改循环；需要保存现场时用显式栈模拟。所以"所有递归都可以转换为迭代"成立。

---

### 第 3 题【202603】任何递归程序都可以改写为等价的非递归程序，但改写后的非递归程序一定需要显式地使用栈来模拟递归调用过程。
**答案：B（错误）**

**解析：** 前半句正确（都能改写为非递归），但**后半句"一定需要显式栈"错误**——尾递归、线性递归（如求 1~n 之和、求阶乘）可以直接改写成简单的循环，**不需要**显式栈。只有无法直接迭代化的递归（如树形递归、多分支递归）才需要显式栈模拟。

---

### 第 4 题【202409】对于已经定义好的标准数学函数 sin(x)，应用程序中的语句 y=sin(sin(x)); 是一种递归调用。
**答案：B（错误）**

**解析：** 递归是指**函数直接或间接调用自身**。`sin(sin(x))` 只是同一个库函数被**嵌套调用两次**（外层 sin 的参数是另一个 sin 的结果），sin 并没有调用自己本身，属于函数嵌套，不是递归。

---

### 第 5 题【202409】在 C++ 语言中，递归的实现方式通常会占用更多的栈空间，可能导致栈溢出。
**答案：A（正确）**

**解析：** 每次递归调用都要在系统栈压入一帧（返回地址、参数、局部变量），递归层数越多占用栈空间越大；相比循环实现，递归确实更耗栈空间，层数过深时可能导致栈溢出。说法正确。
