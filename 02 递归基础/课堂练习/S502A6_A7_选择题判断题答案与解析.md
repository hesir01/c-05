## S502A6 选择题（共 5 题，每题 20 分）

### 第 1 题【202403】计算斐波那契数列的递归代码，时间复杂度是（ ）？
```cpp
int fibonacci(int n) {
    if (n <= 1) return n;
    else return fibonacci(n - 1) + fibonacci(n - 2);
}
```
- A. O(1)　B. O(n)　C. O(2^n)　D. O(log n)

**答案：C**

**解析：** 每次调用会再产生 2 个子调用（n-1、n-2），形成一棵近似满二叉树的调用树，节点数约 2^n 量级，故时间复杂度为 **O(2^n)**。这是无记忆化递归斐波那契的典型特征。

---

### 第 2 题【202312】关于 fiboA（递归）与 fiboB（循环），说法错误的是（ ）？
- A. fiboA() 用递归方式，fiboB() 用循环方式
- B. fiboA() 更符合数学定义、直观易理解，fiboB() 需要转换为计算机程序实现
- C. fiboA() 不仅更符合数学定义、直观易懂，且因代码量较少**执行效率更高**
- D. fiboB() 虽然代码量有所增加，但其执行效率更高

**答案：C**

**解析：** 递归版每次调用有函数调用开销，且会重复计算大量子问题（O(2^n)），**效率远低于循环版（O(n)）**。C 说"递归因代码量少而效率更高"是错误的。A、B、D 均正确。

---

### 第 3 题【202412】关于 fibA（递推）与 fibB（递归），说法错误的是（ ）？
- A. 两个函数实现的功能相同
- B. fibA 采用递推方式
- C. fibB 采用递归方式
- D. fibA 时间复杂度 O(n)，fibB 时间复杂度 **O(n²)**

**答案：D**

**解析：** fibA 用循环递推，O(n)；fibB 用无记忆化递归，两个子调用形成满二叉树调用树，时间复杂度为 **O(2^n)** 而非 O(n²)。D 错误。A/B/C 均正确。

### 第 4 题【202406】下面用循环求斐波那契的 fibo() 函数属于（ ）？
```cpp
int fibo(int n) {
    if (n <= 0) return 0;
    if (n == 1 || n == 2) return 1;
    int a = 1, b = 1, next;
    for (int i = 3; i <= n; i++) { next = a + b; a = b; b = next; }
    return next;
}
```
- A. 枚举算法　B. 贪心算法　C. 迭代算法　D. 递归算法

**答案：C**

**解析：** 函数用 for 循环不断更新前两项的值，从已知项逐步推导出下一项，属于典型的**迭代（递推）算法**，不是递归（没有调用自身）。

---

### 第 5 题【202506】关于分治求最大值的 find_max_recursive，说法错误的是（ ）？
- A. 该算法采用分治算法
- B. 该算法是递归实现
- C. 该算法采用**贪心算法**
- D. 该算法不是递推算法

**答案：C**

**解析：** 代码把数组从中间分成两半，递归求左右最大值再合并，是**分治 + 递归**实现。分治是"分而治之、合并结果"，与"每步选局部最优"的**贪心**不同，C 说法错误。A、B、D 均正确。

## S502A7 判断题（共 5 题，每题 20 分，A=正确 B=错误）

### 第 1 题【202312】以下代码能以递归方式实现斐波那契数列？
```cpp
int Fibo(int N) {
    if (N == 1 || N == 2) return 1;
    else {
        int m = fiboA(N - 1);   // 注意：调用的是 fiboA/fiboB，不是 Fibo 自己
        int n = fiboB(N - 2);
        return m + n;
    }
}
```
**答案：B（错误）**

**解析：** 递归要求**函数调用自身**。这里 Fibo 内部调用的是 `fiboA`、`fiboB`（且未定义），**没有递归调用 Fibo 本身**，因此不能以该方式实现递归斐波那契。注意区分函数名大小写和拼写——函数名不同就不是递归。

---

### 第 2 题【202509】带记忆化（memo）的递归斐波那契时间复杂度为 O(2^n)？
```cpp
long long fib_memo(int n, long long memo[]) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo);
    return memo[n];
}
```
**答案：B（错误）**

**解析：** 记忆化（memo）把每个 n 的结果只算一次并保存，之后直接查表返回。每个 n 只计算一次，时间复杂度降为 **O(n)**，不是 O(2^n)。

---

### 第 3 题【202512】无记忆化的递归 fib 时间复杂度为 O(n)？
```cpp
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);
}
```
**答案：B（错误）**

**解析：** 该递归**没有记忆化**，每次调用展开成两个子调用，调用树节点数约 2^n，时间复杂度是 **O(2^n)**，不是 O(n)。

---

### 第 4 题【202503】递归函数必须具有一个终止条件，以防止无限递归。
**答案：A（正确）**

**解析：** 递归三要素之一就是**递归出口（终止条件）**。没有终止条件的递归会无限调用自身，最终栈溢出崩溃。说法正确。

---

### 第 5 题【202412】递归每次调用自身时，系统都会为新函数分配内存存储局部变量、调用地址等信息，导致递归通常比迭代更耗内存。
**答案：A（正确）**

**解析：** 每次递归调用都会在**系统栈**上压入一帧（局部变量、返回地址、参数等），调用层数越多占用内存越大；而迭代只在固定几个变量间循环。因此递归通常比迭代更耗费内存，层数过深还可能栈溢出。说法正确。
