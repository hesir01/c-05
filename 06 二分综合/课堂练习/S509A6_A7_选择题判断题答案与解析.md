# S509A6 / S509A7 答案与解析

> 来源：GESP 五级真题（2023.12–2026.06 原题）｜专题：二分综合

## S509A6 选择题（共 5 题）

### 第 1 题【202603】`solve(a={1,2,8,4,9}, k=3)` 的运行结果是？
**答案：B（3）**

**解析：** 排序后 [1,2,4,8,9]，check(dist) 统计间距 ≥ dist 能选的点数 ≥ 3。二分过程：mid=4 不可行 → 区间 [0,3]；mid=2 可行 → [2,3]；mid=3 可行 → [3,3]。返回 **3**（选 1,4,8 或 1,4,9，最小间距 3）。

---

### 第 2 题【202509】kthSmallest 矩阵二分，两处横线应填？
**答案：C（`hi = mid;` 和 `lo = mid + 1;`）**

**解析：** 求第 k 小元素（最小可行 x）：`countLE(mid) >= k` 时答案 ≤ mid → `hi = mid`；否则 → `lo = mid+1`。

---

### 第 3 题【202503】二分法在 [1,100] 内猜数，最多猜几次？
**答案：C（7）**

**解析：** 每猜一次排除一半，需要 ⌈log₂100⌉ = ⌈6.64⌉ = **7** 次。

---

### 第 4 题【202312】`_binarySearch` 递归二分，说法错误的是？
**答案：D**

**解析：** 该代码是二分/分治/递归实现的有序查找；**动态规划**需要子问题重叠与最优子结构，与此无关，D 说法错误。

---

### 第 5 题【202312】`_binarySearch` 的时间复杂度是？
**答案：B（O(log N)）**

**解析：** 每次递归区间减半，共 log₂N 层，时间复杂度 O(log N)。

## S509A7 判断题（共 5 题，A=正确 B=错误）

### 第 1 题【202603】lowerBound 代码能正确查找第一个 ≥ x 的元素位置。
**答案：A（正确）**

**解析：** `a[mid] >= x` 时 `r = mid`，否则 `l = mid+1`，是标准的 lower_bound 模板，正确。

---

### 第 2 题【202606】二分查找可以不增加时间复杂度地应用于有序单链表，因为链表支持 O(1) 随机访问。
**答案：B（错误）**

**解析：** 链表**不支持 O(1) 随机访问**（取中点需 O(n)），二分在链表上会退化为 O(n log n)，说法错误。

---

### 第 3 题【202503】每次挑价格最低的商品买，体现了分治思想。
**答案：B（错误）**

**解析：** 每次选当前最优（最便宜）是**贪心思想**，不是分治（分治是分而治之再合并）。

---

### 第 4 题【202512】二分仅适用于有序数据；若数据无序且只查一次，为用二分而排序通常不划算。
**答案：A（正确）**

**解析：** 排序 O(n log n) 再二分 O(log n) 比直接线性扫描 O(n) 更慢（一次查询时），说法正确。

---

### 第 5 题【202403】贪心算法是一种可以应用于所有问题的通用解决方案。
**答案：B（错误）**

**解析：** 贪心只对满足"贪心选择性质"和"最优子结构"的问题有效，不是所有问题的通用解。
