## S503A6 选择题（共 5 题）

### 第 1 题【202309】汉诺塔递归填空：`Hanoi(A, C, B, N-1); cout << A << " -> " << C; _________;` 应填？
**答案：B（`Hanoi(B, A, C, N - 1)`）**

**解析：** 递归三步：① 把 N-1 个盘从 A 借助 C 移到 B（已有）；② 把最大盘 A→C（已有）；③ 把 N-1 个盘从 B 借助 A 移到 C。故填 `Hanoi(B, A, C, N - 1)`。

### 第 2 题【202606】快速幂 `power(x, n)` 体现的编程思想是？
**答案：C（分治）**

**解析：** 快速幂把 x^n 拆成 (x^(n/2))² 的子问题，先递归求一半再合并——典型的**分治**（减半递归+合并结果）。

### 第 3 题【202406】`fun(7)` 返回值为？
```cpp
int fun(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    return fun(n - 2) - fun(n - 1);
}
```
**答案：D（-11）**

**解析：** 递推计算：
- fun(3) = fun(1)-fun(2) = 1-2 = -1
- fun(4) = fun(2)-fun(3) = 2-(-1) = 3
- fun(5) = fun(3)-fun(4) = -1-3 = -4
- fun(6) = fun(4)-fun(5) = 3-(-4) = 7
- fun(7) = fun(5)-fun(6) = -4-7 = **-11**

### 第 4 题【202406】`fun(4)` 输出的序列是？（fun 开头多一句 `cout << n << " ";`）
**答案：C（4 2 3 1 2）**

**解析：** 先输出 4；再算 fun(2) 输出 2；再算 fun(3)：输出 3 → fun(1) 输出 1 → fun(2) 输出 2。按调用顺序输出：**4 2 3 1 2**。

### 第 5 题【202309】字符串反序递归填空：横线处应填？
**答案：A（`sIn[sIn.length() - 1] + sReverse(sIn.substr(0, sIn.length() - 1))`）**

**解析：** 反序 = 最后一个字符 + 前面部分的反序。A 把最后一个字符放前面，再递归反序剩余前缀。

## S503A7 判断题（共 5 题，A=正确 B=错误）

### 第 1 题【202312】十进制转八进制代码能正确输出？
```cpp
char s[10]; ...
s[0] = N % 8 + '0';
rst += string(s);   // 问题：① s 未初始化 ② 低位被追加到末尾
N /= 8;
```
**答案：B（错误）**

**解析：** 两个错误：① `string(s)` 会读到 s 中未初始化的字符（垃圾值）；② 短除法先得到的是低位，却追加在字符串**末尾**，输出顺序反了（应低位放前面或最后倒序输出）。

---

### 第 2 题【202509】分治求解 3 柱汉诺塔时间复杂度为 O(n log n)？
**答案：B（错误）**

**解析：** 汉诺塔递归 T(n) = 2T(n-1) + 1，解得 **O(2^n)**，不是 O(n log n)。移动次数 2^n-1 本身就说明是指数级。

---

### 第 3 题【202506】`puzzle(7)` 会无限递归？
```cpp
int puzzle(int n) {
    if (n == 1) return 1;
    if (n % 2 == 0) return puzzle(n / 2);
    return puzzle(3 * n + 1);
}
```
**答案：B（错误）**

**解析：** 这是角谷猜想（3n+1 问题）：puzzle(7) 过程为 7→22→11→34→17→52→26→13→40→20→10→5→16→8→4→2→1，最终到达 1，**会终止**，不会无限递归。

---

### 第 4 题【202512】递归函数一定要有终止条件，否则可能造成栈溢出。
**答案：A（正确）**

**解析：** 没有终止条件的递归会无限调用自身，系统栈被耗尽 → 栈溢出。说法正确。

### 第 5 题【202606 改编】迭代快速幂时间复杂度为 O(n)？
```cpp
long long power(long long x, int n) {
    long long res = 1;
    while (n > 0) {
        if (n % 2 == 1) res *= x;
        x *= x;
        n /= 2;
    }
    return res;
}
```
**答案：B（错误）**

**解析：** 每次循环 n 减半（`n /= 2`），循环次数约 log₂n，时间复杂度是 **O(log n)**，不是 O(n)。
