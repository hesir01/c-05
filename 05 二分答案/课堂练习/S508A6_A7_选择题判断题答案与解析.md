# S508A6 / S508A7 答案与解析

> 来源：GESP 五级真题（2023.12–2026.06 原题+改编）｜专题：二分答案

## S508A6 选择题（共 5 题）

### 第 1 题【202603】切木头求最大长度，`if(check(mid)){ ans=mid; ____; } else ____;` 应填？
**答案：A（`l = mid + 1; r = mid - 1;`）**

**解析：** 求**最大**可行 x：check(mid) 为真说明 mid 可行且可以更大，左边界上移 `l = mid+1`；否则右边界下移 `r = mid-1`。

---

### 第 2 题【202606】求最小可行 x（`while(l<r)` 模板），`if(check(mid)) ____; else l = mid+1;` 应填？
**答案：B（`r = mid`）**

**解析：** 求**最小**可行 x：check(mid) 为真时答案在 [l, mid]（mid 可能是答案），`r = mid` 收缩右边界。

---

### 第 3 题【202512】切木头使每段 ≤ x（找最小 x），横线处应填？
**答案：A（`if(check(L,K,mid)) r = mid; else l = mid + 1;`）**

**解析：** 求最小可行 x 的标准模板：check 真 → `r = mid`；假 → `l = mid+1`。

---

### 第 4 题【202506】sqrt_binary 二分求平方根，说法错误的是？
**答案：D**

**解析：** A/B/C 均正确描述算法；D ❌：`high_d - low_d >= epsilon` 用 double 比较收敛条件是**可行且常见**的写法（epsilon 是容差），不会死循环，说法错误。

---

### 第 5 题【202603 改编】二分答案求最大 x，`if(check(mid)) ____; else right = mid-1;` 应填？
**答案：A（`left = mid + 1;`）**

**解析：** 求**最大**可行 x：check(mid) 为真 → 尝试更大，`left = mid + 1`；假 → `right = mid - 1`。

## S508A7 判断题（共 5 题，A=正确 B=错误）

### 第 1 题【202312】切巧克力分给 K 个小朋友求最大边长，可用二分法。
**答案：A（正确）**

**解析：** 边长越大能切出的块数越少，满足单调性，可用二分答案求最大可行边长。

---

### 第 2 题【202603 改编】"若 x 可行则所有不大于 x 的值都可行；若 x 不可行则所有不小于 x 的值都不可行"。
**答案：B（错误）**

**解析：** 这只描述了"**越小越可行**"一类问题的单调性。实际问题中可行性可能是"越大越可行"（如切绳子长度），此时单调性方向相反。**不是普适规律**。

---

### 第 3 题【202606 改编】check(mid) 通常 O(n)，二分 O(log V)，总时间复杂度 O(n log V)。
**答案：A（正确）**

**解析：** 二分答案 = 对答案区间二分（约 log V 次）× 每次 O(n) 检查 = O(n log V)。

---

### 第 4 题【202512 改编】用二分求最大 x 时，check(mid) 为真应将右边界更新为 mid-1。
**答案：B（错误）**

**解析：** 求最大 x 时 check(mid) 为真说明 mid 可行且答案 ≥ mid，应更新**左边界** `l = mid`（或 mid+1），而不是右边界。

---

### 第 5 题【202509】二分查找依赖有序性，逐步缩减一半搜索区间，仅适用于数组或基于数组实现的结构。
**答案：A（正确）**

**解析：** 二分要求有序 + O(1) 随机访问，数组满足；链表等顺序结构不适合。
